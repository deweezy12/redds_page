## Project

This repo is `c:\python_work\git\redds_page`, a Vite + React + TypeScript personal portfolio site for Oliver Jan Jarosik. It builds to `dist/` and deploys as a static GitHub Pages site for `theredds.eu`.

## Structure

- `src/main.tsx` mounts the React app.
- `src/App.tsx` defines routes with `wouter`: `/`, `/career-splat`, `/impressum`, `/datenschutz`.
- `src/pages/HomePage.tsx` is the main one-page portfolio and contains most content.
- `src/pages/CareerSplatPage.tsx` embeds the external SuperSplat viewer for `/splats/resized.ply`.
- `src/pages/LegalPage.tsx` contains Impressum and Datenschutz pages.
- `src/components/` contains visual/interactive pieces: stitch background, Gaussian splat tile, chatbot tile.
- `src/styles.css` imports Tailwind CSS and global base styles.
- `src/generated/githubContributionSnapshot.ts` is generated by script and ignored by git.
- `public/assets/`, `public/pdf/`, and `public/splats/` are served from root URLs like `/assets/...`, `/pdf/...`, `/splats/...`.
- `.github/workflows/deploy.yml` installs dependencies, builds with Node 24, and deploys `dist/` to GitHub Pages on push, daily schedule, or manual run.

## Commands

- `npm run dev`: refresh GitHub contribution snapshot, then start Vite.
- `npm run typecheck`: refresh snapshot, then run TypeScript checks.
- `npm run build`: typecheck and build `dist/`.
- `npm run preview`: preview the built site.

## Notes

- Vite `base` is `/` because the site uses a custom domain.
- GitHub contribution data comes from `scripts/fetch-github-contributions.mjs`; if network refresh fails, an existing snapshot is reused.
- `ChatbotTile` uses `VITE_MIA_CHAT_API_URL`; deployment passes it from the matching GitHub secret.
- Keep edits scoped and preserve existing user changes. Do not commit generated `src/generated` or built `dist` unless explicitly asked.
