# Website Ideas

Small backlog for high-leverage portfolio improvements without changing the overall structure.

## Navigation polish

- Show the active section name persistently next to the active left-side scroll dot.
- Keep hover labels for inactive dots.
- Animate the active label transition smoothly while scrolling between sections.

## Motion polish

- Refine section and card reveal timing so entrances feel less uniform.
- Make the side-dot appearance feel tied to scroll progress instead of feeling abrupt.
- Keep shader and background motion secondary to readability.

## Project trust signals

- Add compact project context labels such as `Research`, `Production`, `Thesis`, `Demo`, `PDF`, and `GitHub`.
- Separate action links visually from descriptive tags so project actions read more clearly.
- Make project action rows more consistent across cards.

## Chatbot demo subpage

- Add a personal public chatbot demo page.
- Link to it from the chatbot project card as `Live Demo`.
- Clearly state that it is not the internal work chatbot.
- Allow v1 to be either a real demo or a polished coming-soon page with technical framing.

## Notes

- Keep the current site structure.
- Avoid a large rewrite.
- Prioritize small, high-leverage upgrades.
